# 疑問点管理アプリ

フォルダー・各ファイルの役割と、編集から公開までの流れは [構成案内](docs/STRUCTURE.md) を参照してください。

## 現在の実装（要件実装版）

メール認証、クイック登録、カード詳細・編集、本文・結論、分類、重要度・労力、タグ、検索、解決済み切替、関連カード・グラフ、Markdown・数式プレビュー、ゴミ箱・復元・完全削除、JSONバックアップを実装しています。

**使い方と現在の制限は [機能一覧](docs/FEATURES.md) を参照してください。**

**最初の起動とSupabase接続は [Step 6の手順](docs/STEP6.md) を参照してください。**

GitHub Pagesへの公開は [公開手順](docs/GITHUB-PAGES.md) を参照してください。

技術構成：React / TypeScript / Vite / Supabase。画面・認証・保存処理を分けています。依存関係は `pnpm-lock.yaml` で固定しています。

日常・学習・研究などで生じた「疑問」を記録し、整理し、解決した内容を知識として蓄積するためのアプリです。
基本コンセプト
このアプリでは、疑問が浮かんだ瞬間に記録できることを重視します。
基本的な流れは、
疑問が生まれる
↓
タイトルだけですぐ登録
↓
未整理の疑問として蓄積
↓
後から領域・重要度などを整理
↓
調べる・考える
↓
他の疑問と関連づける
↓
結論を書く
↓
解決済みの知識として蓄積
です。
「きれいに整理してから記録する」のではなく、「まず疑問を逃さず記録し、整理は後から行う」という考え方を重視します。
主な機能
- 疑問のクイック登録
- 未整理の疑問管理
- 領域・分野による分類
- 重要度・必要労力による整理
- タグ
- 疑問同士の関連付け
- 解決済み疑問の知識としての保存
- 検索
- 疑問同士の関係を表示するグラフ
- Markdown
- TeX数式表示
- PC・スマートフォン対応
- アカウント間のデータ同期
開発方針
最初は機能を必要以上に増やさず、実際に日常的に使えるバージョンを完成させます。
その後、自分で使用しながら改善点を記録し、Codexを利用して段階的に改善していきます。
詳細な仕様は SPEC.md を参照してください。
Codexが開発・変更を行う際のルールは AGENTS.md を参照してください。
