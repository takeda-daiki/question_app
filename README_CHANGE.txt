疑問管理アプリ UI改善版

置き換えるファイル
- src/NotebookApp.tsx
- src/cards/QuickAdd.tsx
- src/cards/api.ts
- src/notebook.css

変更内容
1. 「疑問一覧」から検索・絞り込みフォームを除去
2. 検索条件は「検索」タブへ集約
3. 「＋疑問を追加」を「＋クイック追加」に変更
4. 疑問一覧に「＋詳細を設定して疑問を追加」を追加
5. 詳細追加ではタイトル、領域、分野、タグ、重要度、労力、本文、結論を設定可能
6. グラフには領域選択だけを独立表示
7. 疑問一覧のタグを押した場合は検索タブへ移動してそのタグで絞り込む

DB/SQL変更は不要です。
