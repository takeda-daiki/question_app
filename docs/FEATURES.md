# 要件実装版：使い方と実装範囲

## 使い方

1. 「＋ 疑問を追加」からタイトルだけで記録します。「保存後に詳細を追加」を選ぶと、そのまま編集へ進みます。
2. 一覧のタイトルを選ぶと詳細が開きます。本文・結論・状態・重要度・労力・分類を編集して「変更を保存」を押します。
3. 本文・結論ではMarkdownと `$x^2$`、複数行の `$$ ... $$` を使えます。右側（スマートフォンでは下側）に入力中のプレビューを表示します。
4. 「設定」で領域・分野・タグを作ります。領域の色、名前、領域・分野の上下順も変更できます。領域の変更時、カードの分野は未設定に戻ります。
5. 詳細のタグを選択、または関連カードを選んで関連付けます。この2操作は「変更を保存」とは別に、その都度保存します。関連は双方のカードから辿れます。
6. 「検索」で本文・結論・分類・タグも含めて検索できます。空白で区切った語はすべて含む条件です。状態・領域・分野・重要度・労力・タグを組み合わせて絞り込めます。
7. 「グラフ」で領域を選択します。拡大縮小、カードのドラッグ、カード選択から詳細を開く操作ができます。
8. 「ゴミ箱へ」でカードを退避し、「ゴミ箱」画面で復元または確認後に完全削除します。
9. 「設定」の「JSONをエクスポート」で、ゴミ箱を含むカード・分類・タグ・関連情報をダウンロードできます。

## 要件との対応

| 要件 | 実装 |
| --- | --- |
| タイトルのみでクイック登録 | 対応。領域・分野の絞り込みを初期分類に使用 |
| カード詳細、本文、結論、編集 | 対応。未保存で閉じる際に確認 |
| 未整理、重要度3段階、労力3段階 | 対応。未整理は重要度nullで判定 |
| 疑問／解決済み／すべて | 対応。同じカードのstatusを変更 |
| 解決日時 | 既存のqm_sync_resolutionトリガーが管理 |
| 領域・分野の作成、編集、削除、並べ替え | 対応。ただし使用中の分類は先に関連先の変更が必要 |
| 領域の色 | 対応 |
| 複数タグ、タグから一覧 | 対応 |
| 関連カード、逆方向の重複防止 | 対応。DBの既存ユニーク制約と組み合わせる |
| 全文対象検索と条件絞り込み | 対応。現在は取得後にブラウザーで処理 |
| 領域別グラフ、移動、拡大縮小、詳細移動 | 対応。配置は画面内のみ |
| Markdown、TeX数式の即時プレビュー | 対応。生HTMLと外部画像の埋め込みは無効 |
| ゴミ箱、復元、完全削除 | 対応。完全削除はゴミ箱内のカードに限定 |
| メール・パスワード認証 | 対応。認証設定は既存Supabaseと共通 |
| PC・スマートフォン | 対応。下部ナビゲーションあり |
| ホーム画面への追加 | manifestとアイコンを用意。端末のブラウザー機能を使用 |
| JSONバックアップ | 対応。認証トークン・パスワードは含めない |
| 保存状態と失敗時の入力保持 | 対応 |

## 現時点の制限

- オフライン編集、バックアップのインポート、グラフ配置の永続化は未対応。
- 全データを500件ずつ取得しブラウザー上で検索する方式です。数万件規模にはサーバー側検索への移行を検討します。別端末の変更は「再読み込み」で反映します。
- 分類の並べ替えは複数の更新です。通信断時に一部だけ反映される可能性があり、再読み込み後に並べ直せます。
- 分類の削除は使用中なら止めます。カードや分野を移動する一括機能はまだありません。
- JSONエクスポートは読み込み中に別端末で更新しない状態で使ってください。複数テーブルをまとめた同一時点のDBスナップショットではありません。
- 初期仕様の対象外であるAI、共有、SNS、一般公開カード、ネイティブアプリ配布は実装していません。
- Supabaseの既存6テーブルとStep 5のRLS・トリガーを前提とします。今回の実装では本番DBや認証設定の変更はありません。

## 検証と公開

`pnpm build --base=/question_app/` と `pnpm test` で確認します。操作テストはPCとスマートフォンサイズで通信を模擬し、実データを書き換えません。実SupabaseのRLSや複数アカウントの分離を証明するものではありません。

ローカルで確認後、GitHubへコミット・pushすると既存のPagesワークフローが公開版を更新します。GitHubに送る前のローカル変更は、公開URLには反映されません。

公開後の確認：カード詳細を編集して保存→再読み込み→解決済みへ変更→ゴミ箱→復元、分類・タグ・関連付け、別端末で同じアカウントから表示、を確認してください。
