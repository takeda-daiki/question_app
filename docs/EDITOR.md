# 数式・写真・状態変更の使い方

## 数式

文中の数式は `$x^2$` と入力します。独立した数式は `$$x^2$$` と入力します。前後の `$$` の間で改行しても構いません。入力元の文章は変更せず、プレビューを別行表示にします。

```tex
$$
E = mc^2
$$
```

複数の式を縦に並べ、等号の位置を揃える例です。`&` が揃える位置、`\\` が改行です。

```tex
\begin{align}
a &= b+c \\
d &= e+f
\end{align}
```

`align*` も使用できます。環境全体を `$$ ... $$` で囲む書き方も使えます。コードブロックやバッククォートで囲んだコード例は変換しません。数式入力はKaTeXの対応範囲です。

## 写真

1. 写真やスクリーンショットをコピーします。
2. 「詳細を設定して疑問を追加」、または既存カードの詳細を開きます。
3. 本文・結論の挿入したい位置を選び、Ctrl＋V（Macは⌘V）で貼り付けます。
4. プレビューを確認して「保存する／変更を保存」を押します。

選択中の文章があれば、その範囲を画像に置き換えます。通常の文章の貼り付けもできます。スマホは画像をクリップボードへコピーできるアプリ・ブラウザーで、入力欄の「ペースト／貼り付け」を使用してください。画像のURLだけをコピーした場合は文字として貼り付きます。

JPEG・PNG・WebP・GIF、1枚10MB以下に対応します。複数枚の画像がクリップボードに含まれる場合は順番に追加します。途中で失敗した場合は追加済みの画像と文章が残ります。送信中は保存・編集を一時停止します。

保存先は既存のSupabase Storage `qm-card-images` です。非公開バケットとユーザーごとのアクセス設定が必要です。今回のコード変更ではStorageや本番の設定を変更していません。画像のアップロードとカード本文の保存は別処理なので、貼り付け後にカードを保存してください。JSONバックアップには画像参照が含まれますが画像ファイル本体は含まれません。

## 一覧での状態変更

各カードの「ゴミ箱へ」の横に「解決済みにする／疑問に戻す」が表示されます。押すと即時保存します。現在の絞り込み条件に合わなくなったカードは一覧から外れ、対応する「疑問／解決済み」タブに表示されます。ゴミ箱のカードは先に復元してください。
